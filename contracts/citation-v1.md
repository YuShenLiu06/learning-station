# Citation 精确选区切片（M2 #13）

范围：统一材料、AI 回答和练习分区的精确原文位置，复用已有队列、回执、原问题重试和历史快照。补充上下文和 Focus/Git 组合沿 [补充契约](citation-context-v1.md)，组合验证状态以对应 SHA 的证据为准。

## 来源与位置

- 三类现有请求字段各追加可选 `locator:{startChar,endChar}`，从 0 开始、Unicode 码点、半开范围；不是 JS UTF-16、字节或 Git 行号。
- 材料使用 `injections[].{documentId,expectedVersion,selection,locator}`；新本页选句也进入此队列，旧 `selection` 字符串保留兼容，新的本页选句不重复写入该字符串。
- AI 使用稳定 `sessionId/entryId/runId?`、全文 UTF-8 SHA-256 和位置；练习沿既有 `documentId/exerciseEntryId/questionId/part/entryId`、规范分区全文哈希和位置。
- 编辑器选区同时保留所选正文快照；仅当本机保存回执确认同一完整正文落盘时绑定其新版本；本机修改关联元数据时还核对原版本和完整正文相同，才接续该写入回执的新版本。新发送/快捷练习在保存 user 前核对来源；保存未确认、期间再编辑或过期选区均保留输入与引用，不刷新到最新版重绑。
- Rust 按稳定身份、版本与精确原文范围校验，不以字符串第一次出现代替所选位置；旧缺 locator 记录仍可读，不伪造位置。
- 材料引用版本是 Document.version（文件内容哈希），不是 Git OID；存在 Focus 时另沿其同一私有冻结记录与真实固定 Git 检查点，引用选择本身不创建材料 Git。
- 每段 8000 码点/30000 字节、合计最多 8 份等现有限制继续适用。材料选区预算不足整段拒绝，不静默截断。

## 原文与辅助上下文

`quoted_material`、`quoted_ai_answer`、`quoted_exercise_part` 中的 `quotedText` 始终是原文连续子串；locator 指向对应来源正文/规范分区，辅助材料不得塞入该字段。

显式引用按补充契约保存真实段落边界内的必要上下文，选区外正文、同题已保存作答/状态、符合已提交资格的参考内容均单列来源、范围、预算与截断标记，不重定义 quotedText。自动材料仍为独立 versioned 来源；不读取未提交草稿或把含隐藏参考答案的整份练习 Markdown 自动注入。模型可见的引用文本按补充契约本轮生效的真实文本内联格式呈现：文件/版本两行头、上文/引用开始…引用结束/下文、上下文行边界取整与 200/8000 上限，不再输出坐标占位。

渲染定位复用 marked 与既有净化渲染：检查整份可见投影，再从 token 叶子定位所选字符，跳过链接目标、格式标记及代码语言名。重复句按 DOM 范围定位；无法精确映射（如实体、HTML、复杂嵌入）拒绝猜测。练习保留原有规范原文重选入口，不新增弹窗；材料可用现有编辑器重选。AI 回答仍为底部回复或右键回复的一步入口。

## 生命周期

| 情形 | 可观察行为 |
|---|---|
| 预检/旧请求重试并发 | 发送与快捷练习在首次异步保存前占用同一运行编号；停止只释放自己的占用，迟到预检不能接受问题或覆盖当前停止入口 |
| 取消引用 | 输入区/原选区可移除，不产生模型请求 |
| user 真实保存确认 | 消费对应修订票据一次；迟到回执不清新选区或新草稿 |
| 保存未确认 | 引用与原问题保留；按原保存编号核对 |
| user 已保存、模型失败/取消 | 原消息保留冻结引用；重试复用原 user 与快照 |
| 运行结果未知 | 先查询原 run，再决定是否需要新运行的来源校验；来源后来编辑不阻断原回执读取，非 NOT_FOUND 错误不视作未发送 |
| 新快捷生成 | 仅使用当前未消费队列，不取上一轮失败快照 |
| 来源编辑/删除 | 新请求拒绝过期来源；历史原文与旧版本不变，材料打开时提示版本变化；同版本入口使用同一已核实快照，旧异步刷新不得覆盖；未保存本地稿先拒绝打开并保留 |

来源引用仍为不可信内容，不能扩大工具权限。跨会话 AI、外会话练习、未公开参考和伪造/过期身份沿原校验拒绝；课程共享会话归属升级由 #11 负责，本切片不复制其未提交代码。

## 决策样例与本人验收

1. 材料 `前文🙂` 后两次出现“重复句。”，选第二次：保存第二处码点范围，不误指第一处；只记录所选原文，不附整段。
2. 题干 `Explain **force** and motion.` 全选：队列显示规范 Markdown，直接加入，不弹额外确认；未交卷时请求没有参考答案和解析。
3. AI `[重复句。](https://fixture.invalid/重复句。)` 后另有同句，选后句右键回复：稳定消息 ID + 后句位置，不落到 URL 目标。
4. 选句后发送、失败重试、取消、重新加入相同引用：保存前保留，确认后只清旧票据；历史仍显示原文，新快捷生成不重复携带。
5. 发送后编辑来源再打开历史引用：历史显示旧文本/版本，打开来源提示版本已变化，不把旧引用重新绑到新文本。

最终 #13 仍需主会话组合 #11 课程共享会话、#12 Focus 来源与去重、PR45 固定 Git 版本，以及确认需要的按类型辅助上下文；不得把本切片的文件版本称为 Git 冻结版本。

首轮修复还覆盖 AI 菜单传递冻结 locator、编辑后即刻选句/自动保存/保存失败与并发编辑、未知模型结果核对及历史打开竞态；前端实际清单保留并校验可选 locator，旧无位置清单兼容。审查轮次继续由主会话累计。

第二轮修复统一预检与旧重试的占用和停止归属，取消预检保留问题与引用（正文保存可能继续完成）；旧 Rust `locator:null` 按无位置兼容，新清单 None 省略字段，非空伪造位置仍拒绝。真实 Rust None/Some 清单、前端 Run/历史映射与模拟 IPC 并发取消回归各自单列，不视为原生 GUI 验收。
