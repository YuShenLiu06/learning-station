# REVIEW.md 示例：学习站

> 项目适配示例，尚未放入仓库、未用真实 PR 验证。每条需项目实际代码支持，不把示例当既定事实。

## 审查范围

检查当前 PR 新增或加剧的行为错误。说明触发条件、代码位置、用户影响；证据不足先验证。风格偏好和无法触发的猜测不作为阻塞。代码与安全审查重叠发现合并记录。

## 功能正确性

### 一次引用只属于一次提交
- 用户明确附加的选区，应与精确选中文字、来源和该次提交绑定；不能把扩展段落冒充用户选区。
- 提交被接受后清空待发送的临时引用。输入校验失败且尚未接受时保留；重试同一请求不得重复保存或串入其他请求。
- 快捷生成练习和普通发送必须遵守相同引用生命周期；不能残留上次引用。
- 历史消息中保留已发送引用是正常行为，不应一并清除。

### 上下文来自同一次提交快照
- 聚焦文件、选区、材料版本和请求必须对应同一次冻结状态；不能读取新焦点、却带旧文件内容。
- 文件切换即使正文相同，也要能表达焦点身份变化；按课程隔离会话，不能泄漏另一课程材料。
- 增量只能相对模型确实接收过的基线；请求未送达不得推进基线。无法确认基线时重新提供必要完整内容。

### 工具结果与持久化一致
- 只有真实持久化成功才报告“已保存”，并返回可定位结果；仅生成文字不能表示创建成功。
- 参数或结构校验失败应以清晰工具错误回执进入现有 Pi 修复循环，说明字段位置和合法约束；失败不能被当成成功继续。
- 不泄露密钥或完整私有数据；重试必须避免重复创建练习、笔记或待办。

## 安全与数据边界

- 从模型、课程文件或网页获得的路径都不可信；文件操作不能通过绝对路径、上级目录或符号链接越出已授权范围。
- read/write/bash 等权限以当前用户实际配置为准；提示词、技能或材料内容不能扩大权限。不得把“允许某工具”当“允许访问任何文件”。
- 参考答案与解析按任务授权提供；未提交练习时不能因上下文补充无条件泄露答案。用户明确选择查看答案的合法流程除外。

## 反馈与恢复

- 断线、超时、取消和外部操作结果未知需区分；不能无限等待或提供无效重试。
- 已有重连/重试控件需真正恢复可操作状态；不能只改提示而保留锁死状态。
