# 学习站 · 本机预览

打开根目录的 [学习站.app](学习站.app)，在“打开或粘贴我的材料”导入 Markdown 或纯文本。若还开着旧“本地学习预览”，先退出再打开此版。也可从空库入口使用原创、可编辑的 [英语学习模板](templates/english-learning.md)。

可用流程：阅读编辑 → 保存困惑 → 手动添加题目并作答 → 记录自己的错因 → 按主题复习、导出 Anki CSV。右侧“全展开”可探索或做题，“恢复阅读”返回三栏，输入与进度保留。各模块也可单独使用。

待办不必设时间；明确开启提醒并选时间才进入通知箱。应用退出或 Mac 休眠时不能准时提醒，重开后补入。

原文在 `library/courses/`，记录在 `library/sessions/`。自动保存遇冲突会保留输入；关闭前保存正文与草稿，失败会保留窗口。退出后备份请同时复制 `library/` 和 `~/Library/Application Support/cn.yushen.learning-station/`。

**真实 AI 尚不可用。** GLM-5.3-flash Coding Plan 是否适用本应用仍待确认；AI发送、密钥配置和测试保持禁用，不改用按量计费API。Pi五项工具已完成本地测试，不能据此称真实模型联通。自动学习报告、独立错题本容器尚未实现；已有错因记录与复习可用。飞书发送未启用；Anki CSV不是同步。

本版为 macOS arm64 本机预览，无安装器、未签名或公证。模型适配依赖本机已有 Node 24，首屏不启动它。详见 [README](../README.md) 与 [README](../README.md)。
