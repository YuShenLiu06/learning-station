# 学习站 · 统一验收版

当前包为“学习站-统一验收版.app”。请先正常退出旧学习站，再打开新包；复用原有本机库与设置。旧包与正在运行的窗口不会被构建任务覆盖。此版尚未做本轮原生和真实服务验收，见[README](../README.md)。

在“学习”新建课程、目录，导入 Markdown 或写笔记；点击“探索”直接输入新问题，内容保存为普通笔记；每次进入为空白，旧探索只从“历史”主动打开，已有记录与草稿保留。右侧助教的模型靠近输入框，Enter发送、Shift+Enter换行。选句操作区保持固定，输入框内的本次附加引用可移除，发出的问题保留各自的引用请求；实际使用来源仍以该次生成记录为准。右键资料或正文选段可明确加入本次参考；目录不会自动带入整课，发送时重新核对并冻结来源版本。

手动引用在本条问题真实保存后自动收起；失败消息仍能按原引用重试，后来新增引用不受旧回执影响。可从AI回答原文选段加入下一问，来源变化会提示重选；每条回复保留自身来源。做题页可直接选择题干、已保存作答、公开反馈或已展开参考，加入同一引用区；跨题、跨分区和未提交草稿不会冒充持久原文。自动聚焦文件未实现，整份含答案练习仍不能作为普通资料引用。

来源区新增“上下文桥”投影清单，区分新增、沿用、更新及重载，并明确部分范围。自动资料的基准失效时重新载入正文；主动资料查询照常返回实际正文片段。它不保证减少无状态 API 的总输入 token。实现与扩展见 [ContextBridge](docs/context-bridge.md)。

在“设置→供应商→生成限额”可独立保存输出上限，上下文容量未知留空；换模型后核对服务支持值。达到输出预算会保留可用内容并提示，思考也可能消耗该预算，不会自动重发。

探索与出题会由程序附带对应学习指导，不需要模型自行调用；每次生成固定指导版本。项目内另有AI复习指导，纯Anki翻卡与评分不会因此启动模型。

保留原有练习按钮：可直接在输入框写题型、难度等要求，再生成练习，不限定学科。题目形成子文档，在题下作答；客观题由代码核对，主观题保存答案后请求AI批改。批改模型可单独选择并复用当前供应商和凭据；按固定量表给分，无量表只给评语。原文批注、遗漏要点、修改建议和本人错因分别保留，完整参考默认折叠；失败不会冒充评价完成。

“复习”优先连接本机已有的 Anki/AnkiConnect，读取到期卡、显示答案、写回复习结果；本机卡片可按课程筛选并明确送入所选牌组，保留学习来源。未连接时，需你自行打开已有 Anki 后检查连接；CSV只是备用导出，不是同步成功。外部卡片没有学习站来源时会明确标明。

“设置→通知”配置本人专用飞书机器人：收取与发送默认关闭，保存不联网，密钥只存本机Keychain，启停均由本人触发。长连接收事件，HTTP发送消息；只处理指定本人和唯一聊天。启用发送后仅派发新到期提醒及手动测试，旧历史不补发、未知结果不重发；收到消息只进入站内通知，不自动执行或调用AI。详见[飞书配置](docs/feishu-setup.md)。应用退出或休眠时不保证及时提醒。

支持可恢复回收、课程图片/代码资料、左右栏调宽、字号与草稿恢复；代码不执行。正常退出全部学习站后，同时备份 library/ 和 ~/Library/Application Support/cn.yushen.learning-station/。本包未签名、仅macOS arm64，随带现有Node24与受审SDK，无安装器、没有公开部署。真实AI批改、Anki调度、飞书收发及本轮原生界面均待验收；联网工具、学习文件创建编辑与课件尚未在本版实现。
