# 学习站 · 本机预览

本轮请先保存并退出当前学习站窗口，再打开根目录的 [学习站修复.app](学习站修复.app)。当前正在运行的旧窗口不会被替换。随后在“打开或粘贴我的材料”导入 Markdown 或纯文本。若还开着旧“本地学习预览”，先退出再打开此版。也可从空库入口使用原创、可编辑的 [英语学习模板](templates/english-learning.md)。

可用流程：阅读编辑 → 保存困惑 → 手动添加题目并作答 → 记录自己的错因 → 按主题复习、导出 Anki CSV。提问框按 Enter 发送、Shift+Enter 换行；中文选字不触发发送。右侧“全展开”可探索或做题，“恢复阅读”返回三栏，输入与进度保留。各模块也可单独使用。

待办不必设时间；明确开启提醒并选时间才进入通知箱。应用退出或 Mac 休眠时不能准时提醒，重开后补入。

原文在 `library/courses/`，记录在 `library/sessions/`。自动保存遇冲突会保留输入；关闭前保存正文与草稿，失败会保留窗口。退出后备份请同时复制 `library/` 和 `~/Library/Application Support/cn.yushen.learning-station/`。

可在“设置与连接”手动填写OpenAI Chat Completions兼容服务的基础地址、模型ID和密钥。保存不发请求，测试和提问只调用你保存的目标，按所选服务规则计费；地址或协议改变需重新输入密钥。若保存的是 Coding Plan 专用地址，界面会说明本地用途限制，测试按钮只查看限制、不发送请求。可保留配置等待确认，或自行填写获准使用的普通 API 配置；应用不会自动换通道。自定义配置与外部账户尚需分别验收，不能把本地协议fixture当作在线AI联通。

探索可选择是否关联当前小节；关闭关联会使用独立学习记录，不自动带入当前正文或选句。字号可在设置中调整。AI创建的待办默认无提醒，即使有时间也需你之后明确开启。

自动学习报告、独立错题本容器尚未实现；已有错因记录与复习可用。飞书发送未启用；Anki CSV不是同步。

本版为 macOS arm64 本机预览，无安装器、未签名或公证。模型适配依赖本机已有 Node 24，首屏不启动它。详见 [README](../README.md) 与 [README](../README.md)。
