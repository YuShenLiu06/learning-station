# 学习站 · 本机预览

阅读自己的 Markdown，选段提问、练习，并把错因和复习卡留在同一学习空间。

打开 `src-tauri/target/release/bundle/macos/学习站.app`，点击“打开我的学习材料”，选择文件或粘贴正文。课程存于本项目 `library/`；学习记录另存，课程原文不会被聊天覆盖。

- 编辑正文会自动保存；遇到外部文件冲突会保留输入，可另存草稿。
- 使用 AI 前，在“设置与连接”输入你批准使用的 API 地址、模型和密钥，保存后测试。密钥保存在本机钥匙串。
- “复习与历史”按主题找回旧错，支持导出 Anki CSV；导出不等于同步。
- 待办可以不设时间；只有明确开启提醒并选择有效时间才提醒。应用退出或 Mac 休眠时不能准时提醒，重开后补入通知箱。

**当前为预览：真实模型尚未配置验证；飞书发送未启用，Anki 接口未连接。** AI 讲解／生成练习需真实 API；示例与离线测试不能证明在线服务已接通。高级情境规划、课程自动重写、Git分支与插件平台不在本轮。

构建：`npm ci` → `npm run tauri build -- --bundles app --no-sign --config '{"bundle":{"active":true}}'`。开发与验收记录见 `docs/`，接口见 `contracts/ipc.md`。
