# 学习站 · 本机预览

完整无框版本已构建；最终原生验收暂停，尚未替换既有用户入口。当前构建仅供继续验收，结果与剩余项见 [README](../README.md)。

从左侧“学习”新建课程和文件夹，导入 Markdown/纯文本，或新建普通笔记。也可使用原创可编辑的 [英语学习模板](templates/english-learning.md)。“探索”先显示记录，点唯一的“开始探索”后输入问题；问题与产物保存在固定“探索”目录的普通 Markdown 笔记中。未配置模型时也可先保存在本机。

右侧助教使用正文、选区和本人显式关联的材料；目录归属不会自动带入整课。模型 ID 在输入框下方切换。Enter 发送、Shift+Enter 换行；发送后可继续写下一条。失败重试复用已保存问题，未知结果先核对原请求。

生成练习或手动加题会形成可导航子项。直接在中心对应题下作答，查看参考和解析、保存本人错因，再到复习页标记“再练一次/已理解”，按当前筛选结果导出 CSV。开放题供参考和本人检查，不冒充自动评分。课程资料可添加图片或代码/文本并插入受控引用；代码不执行，图片本轮不送视觉模型。

树节点右键可预览整个子树再移入回收区；从回收区按原 ID 恢复。原文和资料保留，回收中的内容不会进入新请求；原文件被外部修改时，恢复会明确阻止并保留现状。本版不提供永久删除或清空回收区。

设置分供应商、外观、通知。支持自定义 OpenAI Chat Completions 和 Anthropic Messages，显示精确请求目标，不自动补前缀。保存不发请求；更换地址或协议需重新输入密钥。Coding Plan 专用通道保留本地用途限制，生成中更换模型须先停止。

顶栏可分别收起左右栏；左右栏的分界线可拖动或用方向键调宽。字号、宽度和导航偏好保存在本机。保存冲突保留输入；关闭前保存正文与草稿，失败保留窗口。备份时正常退出全部学习站，再同时复制项目的 library/ 和 ~/Library/Application Support/cn.yushen.learning-station/。

待办默认无提醒，选时间并明确开启才进入通知箱；退出或休眠期间重开补入。飞书仅显式点击“发送测试消息”才发固定本人测试文本，不自动开启全部提醒。工具保存以真实回执为准，AI 整理的笔记和错因建议仍需本人确认。

此版为未签名 macOS arm64 本机预览，使用已有 Node 24，无安装器。Anki 仅 CSV；自动报告、独立错题本、学习 Skill 尚未实现。真实在线模型与飞书发送本轮未验证；localhost 验收不代表外部联通。详见 [README](../README.md) 和 [README](../README.md)。
