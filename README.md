# 学习站 · 本机预览

本轮正在完成探索、目录、练习、复习和课程资料的统一集成。此前“学习站候选.app”只是历史中间版，不代表本轮已验收；完整验收前不再交付新中间包。当前用户窗口与应用保持原样。导入 Markdown/纯文本，或从空库使用原创、可编辑的 [英语学习模板](templates/english-learning.md)。

可用流程：阅读编辑 → 保存困惑 → 手动加题或由AI生成练习 → 作答、记录错因 → 按主题复习、导出 Anki CSV。各模块可单独使用。Enter 发送、Shift+Enter 换行；发送后问题进入消息区，可继续写下一条草稿。失败时按消息状态重试，已保存的问题不重复创建。

供应商配置在独立设置页，支持自定义 OpenAI Chat Completions 和 Anthropic Messages。界面显示精确请求目标，不自动补地址前缀：OpenAI 基础地址需要 `/v1` 时请自行填写；Anthropic 基础地址不带末尾 `/v1` 或 `/messages`。保存不发请求，测试与提问只访问已保存目标；更换地址或协议需重新输入密钥。同一连接可在聊天顶部只换模型ID，生成中先停止再切换。Coding Plan 专用通道保留本地用途限制，应用不会自动改付费通道。

探索可关闭小节关联，独立记录不带当前正文或选句。右栏左边缘可拖动或用方向键调宽，字号与宽度保存在本机。AI工具卡依据真实执行回执显示；“待确认”的学习笔记和建议错因仍需本人判断。

待办默认无提醒，选时间并明确开启后进入通知箱。应用退出或 Mac 休眠时无法准时提醒，重开后补入。设置页可查看飞书通道状态；只有点击“发送测试消息”才向已验证本人通道发固定文本，不会开启全部提醒。未知结果先核对原请求，避免重复发送。

原文在 `library/courses/`，记录在 `library/sessions/`。自动保存遇冲突会保留输入；关闭前保存正文与草稿，失败会保留窗口。退出后备份请同时复制 `library/` 和 `~/Library/Application Support/cn.yushen.learning-station/`。

自动报告、独立错题本和学习Skill尚未实现；Anki仅CSV导出。外部模型与真实飞书发送本轮未验证。此版为未签名 macOS arm64 本机预览，无安装器，模型适配使用本机已有 Node 24。构建与各层测试边界见 [README](../README.md) 和 [README](../README.md)。
