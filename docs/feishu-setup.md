# 配置本人飞书机器人

应用内入口：设置 → 通知 → 本人飞书应用。SDK与Node随包提供；无需安装CLI、Python或后台服务。没有配置时，站内待办与通知仍可使用。

1. 在飞书开放平台创建独立企业自建应用并启用机器人，可用范围只选本人；机器人只加入你选定的聊天。
2. 按组织规则申请应用身份的发消息、接收本人私聊权限；只有选群聊时才申请机器人被@的消息权限，不申请全群历史、通讯录或附件权限。具体权限名称与组织审批以控制台为准。
3. 事件订阅选“使用长连接”，仅添加 im.message.receive_v1。按控制台说明取得应用专属本人的 open_id 与目标 chat_id；学习站不会扫描聊天列表或猜测身份。
4. 在学习站填写 App ID、本人 Open ID、唯一聊天 ID 与 App Secret。密钥只在本机输入，提交即清空并写入学习站独立Keychain项；不要发到此聊天。收取与发送分别选择，保存不会连接。
5. 点击“启动飞书服务”。收到“接收已连接”才表示长连接建立；可在目标聊天发一条测试文字，查看站内通知。另行启用发送后，明确点一次“发送测试消息”，只有真实消息编号才算发送成功。

更改绑定先停止服务，再输入新凭据。发送结果未知时先查看飞书消息和原请求回执，不换编号连点。关闭应用或休眠会中断服务，不保证离线期间完整补收，也不自动补抓历史。

当前只通过离线SDK帧、管道和持久化测试，未用真实应用授权收发。官方依据与详细边界见[适配器契约](../contracts/feishu-bot-node-v1.md)。
