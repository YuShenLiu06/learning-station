# Learning Station v0.1.0

在同一个本机学习空间阅读材料、向助教提问、做练习、保存笔记并安排复习。

完整功能与变化见 [更新记录](../../CHANGELOG.md)。

## 发布状态

本页对应 v0.1.0 早期版本，下载 macOS Apple Silicon 安装包与校验信息见[正式发布页](https://github.com/YuShenLiu06/learning-station/releases/tag/v0.1.0)。

桌面目标为 macOS Apple Silicon，其他平台尚未验收；开发构建未进行 Developer ID 签名或公证。

## 使用前

- AI 功能需要自行配置获准使用的模型地址与密钥，模型调用遵循服务方的用途与计费规则。
- Anki 复习需要本机已有 Anki 与 AnkiConnect，未连接时可使用本机复习卡和 CSV 导出。
- 飞书通知需要配置本人的机器人并手动启动服务，配置步骤见 [飞书设置](../feishu-setup.md)。
- 工具权限默认关闭，HTML 仅静态预览，图片附件仅本机预览，应用退出或休眠时不保证准点提醒。

## 验证边界

本人已于 2026-10-24 确认逐处审批候选验收通过，并明确同意带已知问题发布，相关大文档修复后置到 v0.1.1。普通正文支持逐处接受或拒绝，已接受内容立即保存，重新打开后可以继续处理剩余修改；练习继续按整题审阅。

最终候选在 macOS Apple Silicon 构建，局部逻辑、模拟原生接口与实际应用操作分别记录在[逐处审批验收记录](../acceptance/partial-edit-review.md)。CI、代码审查和安全审查以各 PR 对应提交的实际记录为准，未完成项不视为通过。

本地或 CI 检查不代表真实模型、Anki 用户牌组或飞书账户全部通过端到端验收；未进行 Developer ID 签名和公证，其他平台未验收。

## 超大附件来源编号怎么测试

使用隔离回归测试，不操作真实资料库：

```sh
cargo test --locked --manifest-path src-tauri/Cargo.toml --no-default-features 'material_git::course_tests::oversized' -- --test-threads=1
```

预期 3 项通过，覆盖以下行为：

1. 通过真实导入入口登记一份小附件，再将同一物理文件扩大到 5 MiB + 1 字节；材料快照排除记录的 `asset_id` 必须等于导入时返回的编号，原因是 `capacity_exceeded`。
2. 大文件正文不进入新快照，其他小材料仍能被捕获，旧固定快照仍可读取原小附件。
3. 未登记目录，以及已登记目录中另放的超大文件，其来源编号仍为空，不能继承已登记附件的编号。

还原旧实现时，第 1 项会因编号为空而失败，已保留红灯证据；恢复修复后通过。

当前聊天界面尚不能用于可靠复现此项：聚焦组装仍会调用既有附件列表校验，已登记文本超过 1 MiB、图片超过 5 MiB 会先被拒绝，可能阻止后续请求。快照排除记录正确不代表该界面路径已经走通。不要在真实课程中扩大附件后尝试发送；应用交付目录提供可双击的隔离测试脚本。
