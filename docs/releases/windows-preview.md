# 学习站 Windows x64 预览版

双击 `learning-station-v0.1.0-windows-x64-preview-setup.exe` 安装到当前用户目录，再从开始菜单打开“学习站”。本版未签名，尚未完成本人 Windows 实机验收。

基于 v0.1.0 发布源码，增加 Windows 打包、Node x64 运行时、系统凭据存储和启动适配。安装器自带 Node；WebView2 缺失时安装器需要联网安装。课程版本记录需要另行安装 Git for Windows 到默认目录。

## 范围与限制

- Windows 安装与启动的自动检查结果、源码提交和 SHA-256 见随包 `build-evidence.json`、`SHA256SUMS.txt`。
- 课程正文的受控写入、AI 正文修改审批与相关恢复事务尚未适配 Windows，会拒绝写入；本版不能替代 Mac 版的完整功能。
- 命令工具依赖 `/bin/bash`，Windows 预览中不可用；请保留关闭档位，普通学习工具与受控读写档位不因此扩大权限。
- 真实模型、凭据跨次重开、Anki、飞书及完整学习流程未在 Windows 本人验收。v0.1.0 已有的大文档边界问题仍保留。
- 在 Windows 上显示文件位置会打开所在文件夹。预览验收建议使用新建测试课程和合成资料。

## 本人验收

安装并启动，确认能进入主界面；新建测试课程并导入一份 Markdown，重开检查资料；配置本人允许使用的模型，测试连接并提问。受控正文写入按上述限制处理。预览包不代表已正式发布或验收通过。
